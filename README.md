# SPECTRR LLC — Diseño y Elaboración de Planos 3D Online

Sitio web corporativo y plataforma digital de **SPECTRR LLC**, estudio especializado en el desarrollo integral de proyectos técnicos arquitectónicos, modelado BIM y **diseño de planos 3D 100% online** para clientes en todo Estados Unidos y el mundo.

---

## 🚀 Características Principales

- **Identidad Visual Moderna**: Paleta contemporánea basada en Naranja (`#ff6903`), Gris Arquitectónico (`#4e4d53`), Acento Ámbar (`#ffb850`) y Modo Oscuro profundo (`#0b0c0e`).
- **Visor Comparativo Interactivo**: Simulador deslizable en tiempo real que contrasta planos técnicos CAD (`sala.png`) con renders arquitectónicos fotorrealistas 3D mediante tecnología CSS `clip-path` y JavaScript.
- **Cotizador de Presupuesto Dinámico**: Calculadora de estimación en tiempo real por metraje cuadrado y tipo de plano (Arquitectura, Estructuras, MEP), con enlace directo para pre-llenar y enviar solicitud por WhatsApp.
- **Portafolio con Filtros en Vivo**: 12 proyectos técnicos clasificados en Comercial, Residencial, Corporativo y Vertical, acompañados de visor modal lightbox de alta definición.
- **Tooltips y Microinteracciones**: Glosario técnico interactivo y botones con estados animados para optimizar la experiencia de usuario (UX/UI).
- **Diseño 100% Responsive**: Experiencia cuidada tanto para computadoras de escritorio como para teléfonos móviles y tablets.
